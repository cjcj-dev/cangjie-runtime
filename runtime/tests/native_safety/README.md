# Native safety regressions

`rwlock.cpp` consumes the real RwLock header. Compile with the product include directories, C++17 and pthread, then run. For deterministic memory-order regression, also compile with Clang `-O1 -S -emit-llvm`: the `cmpxchg weak` in each of `NativeSafetyLockWrite` and `NativeSafetyTryLockWrite` must have success `acq_rel`, failure `monotonic`. Reverting either product CAS to `release` must fail that check. The contention run alone on x86 cannot prove weak-memory correctness.

`allocator.cpp` links the normal native runtime static archive, CJThread and boundscheck (no allocator/TLS/PagePool stubs). Run as a fresh process with `1152` (non-dividing), `1025` (rounds to 1152), and `1024` (dividing control). Each process exhausts more than two spans, checks the whole aligned block before writing the requested bytes, checks all payloads, frees through NativeFree, flushes the real TLS ThreadCache, checks that PageCache received the spans, and repeats for cached reuse. Revert only CentralCache's loop condition, rebuild the product archive, and require exit 42 at FULL_BLOCK for 1152/1025 while 1024 still passes. Restore and rebuild before the recovery arm. This finite native test does not initialize or qualify the GC or a complete SDK.
