# Managed Monitor linker classification

Compile `linker_monitor_managed.cj` with the ordinary public cjc driver, `-O0 -j1 --apc=1 --lto=full --static --static-std`, the newly installed std CJO/core bitcode/archives and normal native runtime install. Compile `linker_monitor_managed.cpp` with the product CXX configuration and link its archive into that executable. Use the real installed `cjstart.o` and `cjld.lds`; do not call a copied classifier or set StackManager boundaries in the test.

The native bridge queries the installed static StackManager classifier after normal runtime initialization. A cjc-generated `@C` function whose name contains Monitor must be classified as user code, a plain managed function remains user code, and the native `MonitorR05Control` function remains runtime code. Target rc is 0. A `control` argument disables only the user assertion, keeping both independent native/plain checks.

For the product cut, change the isolated consumer's actual installed script `.text.Monitor*` back to `.text.*Monitor*`, then link through the same driver. Expected target rc is 41 at `R05_CLASSIFIER_ASSERT`, with native=1/user=1/plain=0; the control must remain 0. Restore the original installed script bytes, relink and rerun both. Preserve cjc stages, map, intermediate sections, ELF identity, script identity and own exit codes. This checks real classification of cjc-produced code; it does not qualify arbitrary stack unwinding or other platforms.

The adopted cand5b public compiler rejects the hidden options `--ffunction-sections` and `--llc-options=-function-sections`; those first failures remain evidence. Its visible `--lto=full` entry uses the paired SDK LLD and emits individual managed function sections without a driver change. Ensure the consumer installation includes the original `third_party/llvm/bin/lld` launcher and `.entry`, `.native-tools/third_party/llvm/bin/lld` body and `ld.lld -> lld` tool alias, with the original paired libLLVM. Do not substitute an internal llc call or manually assigned C sections.

Pass `--link-option --save-temps` to preserve the LLD `.lto.o`, and `--save-temps DIR` for frontend/opt output. Check `.text.R05UserMonitorScope` and `.text.R05PlainScope` in that object, and preserve the verbose driver command and link map identifying the actual installed startup, runtime and new std core bitcode. This static configuration does not load a target std shared library; shared-library consumer evidence belongs to its separate dynamic configuration.
