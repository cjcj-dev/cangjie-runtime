# Suspension ordering

The three `ir.cpp` functions consume the actual Mutator header. Compile them with the selected product build's definitions/includes and `-O1 -S -emit-llvm`; `check_ir.mjs` requires one SC i32 flag load in each. Reverting the three product loads to acquire must give checker rc6; restore the header and repeat. Also preserve actual `Mutator.cpp` IR and the ordinary `MRT_LeaveSaferegion` load/store ordering. This is an IR contract check, not an old-machine failure claim.

Compile `callback.cj` through the matching normal compiler/CJO installation, linking `callback.cpp` against the independently installed candidate runtime. Main calls ordinary foreign `R06Invoke` (C2N); the native function invokes its Cangjie `@C` callback (N2C). The existing logical mutator must already be safe on entry. A separate native requester uses the actual manager StopTheWorld/StartTheWorld pair. It publishes a request before callback entry and waits until the product SuspendForSync clears SYNC. At that point the managed callback must not have reached `R06Reached`; after StartTheWorld it must run exactly once. The no-STW invocation is an independent control.

The bounded rendezvous adds synchronization. Old acquire can also pass it. It verifies actual product ingress/stop/resume wiring and is not a probabilistic memory-order reproducer. There is no phase/ABI change, fake flag, forged unwind status, copied runtime implementation or new product export. A watchdog around the entire executable is required in case the existing STW operation itself fails to complete. Preserve its own rc, log and loaded runtime identity. Source presence is not an executed result.
